# Pattern Vault

A hands-on catalogue of the classic Gang-of-Four design patterns,
implemented in Java on a minimal Spring Boot skeleton. Each pattern lives in
its own package under `src/main/java/com/prep/pattern_vault`, grouped by
category: `creational`, `structural`, `behavioral`.

## Documentation

Full reference material — intent, structure diagrams, how each
implementation maps to the pattern, usage examples, and notes on any
deviations from the textbook form — lives in [`docs/`](docs/README.md).

## Build & test

```bash
./mvnw compile
./mvnw test
```
